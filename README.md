# bumptima-esp

ESP32-WROOM-32UE firmware — Lonely Binary Gold Edition board.

See [SPECSHEET.md](SPECSHEET.md) for full pinout, boot constraints, and peripheral reference.

## Board

- **Module:** ESP32-WROOM-32UE (external U.FL antenna)
- **Onboard RGB LED:** WS2812B on GPIO2 (labeled "RGB 102" on PCB)
- **USB:** USB-C
